Classic Companion iOS Privacy Policy

Last updated: August 28, 2026

1. Privacy Model

Classic Companion is designed for focused reading and respects user privacy. The application does not require users to create an account in order to read the included classical works.

2. Reading Content

Classic Companion presents classical texts and supporting reading materials within the application. Users do not need to submit personal information in order to access and read this content.

3. Reading Aids

Features such as pronunciation guidance and contextual word notes are provided to support reading. These features are designed around the text being read and do not require users to provide personal information.

4. Data Collection and Tracking

Classic Companion currently does not use advertising tracking, analytics services, CloudKit synchronization, or a user account system, and it does not sell users' personal information. If future versions introduce features that require additional data handling, this privacy policy will be updated accordingly.

5. User Control

Users may remove the application and its locally stored application data through the standard controls provided by iOS or iPadOS.
